# Product guides

Rules that the API and the clients both follow live here. An event's lifetime, who may hold one, and how large its gallery may grow are that kind of rule: they are the product, and each app implements them.

How a single side is built stays next to that side. `api/docs` covers the NestJS service, its jobs, and its HTTP contract. `mobile/docs` covers the Expo app. When a rule changes, change it here first, then change the implementation to match.
