# Test cases

Every manual test case for the mobile app, by area. IDs, priorities and results are explained in the [README](README.md). **Last result** is from the most recent run in [runs/](runs/) (2026-11-10, iPhone 16 Pro simulator, iOS 18.4, local API) unless it says otherwise.

Roles: **host** (organizer), **guest** (adds photos), **viewer** (view only), **outsider** (signed in, not on the roll), **signed out**.
